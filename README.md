# Deviser-E-Ticket-

DEVISER ’26 — Bandaranayake College Gampaha, 2021 A/L Batch Reunion.

Static website: open index.html through a local web server. All website files and supplied artwork are included. No build step is required.

## GitHub Pages
In repository Settings → Pages, select Deploy from a branch, then main and / (root), and Save. GitHub will show the published website URL once deployment completes.

## Features
Original ticket 3D preview, subtle animated school flag background, ticket quantity and WhatsApp inquiry, responsive styling, small SD vector credit. Preview labels and animation control buttons were removed as requested; DEVELOPMENT BY is uppercase.

Bookings are enquiries to the organiser; this site does not process payments or issue tickets. Artwork and school identity remain the property of their respective owners.
